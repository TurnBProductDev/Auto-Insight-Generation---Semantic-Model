# SB Mart Summary rules

- Start with Overall Performance, then cover only the selected material business areas.
- Use Division and Section as the distinct merchandise levels. Department and Category
  currently mirror those levels and must not produce duplicate sections.
- Include complete ranked coverage for every Division, Section and Store.
- For every selected area, explain revenue, quantity and supported transaction movement,
  the largest positive and negative contributors, and the leading store evidence when
  available.
- Describe partial evidence honestly as the largest returned contributors, never as the
  full share of the business.
- Treat the unit/rate split as volume and rate/mix. Never describe rate/mix as pure price.
- Use July 2026 only as the current onboarding anchor. Each run must resolve the latest
  complete month again from the model.
- Never use the model's batch/load dates for daily or weekly claims.
- Use professional, plain language, no emojis, and no unsupported causal statements.
- When chart-ready evidence exists, include at least one useful interactive chart.
