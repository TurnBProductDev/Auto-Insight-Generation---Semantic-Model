Important things to know about these numbers

  • There is no comparison with last year. The report only holds 2026 data, so every figure here is compared with target, never with last year.
  • No causes are given, only amounts and places. The report holds sales and targets. It does not hold promotions, stock levels, staffing or footfall, so nothing here explains why sales moved — only where the difference sits.
  • Each period is compared with the target for the days that have passed, not with the target for the whole period. Full-period targets are used only in the “what is needed to catch up” figures, which say so.
  • Branch CFH022 is not included, matching how the Sales performance report treats it.
  • Projections carry a current rate forward. They are arithmetic, not forecasts, and they assume the remaining days keep the targets they already have.
