What this report does not show

Stock value is calculated differently on the two dates being compared, so this report compares units and shares only. ST5 holds the same quantity of stock on both dates (79,838 units) but its value has moved from 0.78 to 0.21 per unit. Stock that did not move cannot change in worth, so the way stock value is calculated has changed between the two dates. Value figures are therefore not compared here.

The semantic model's [aged stock share] was excluded: its numerator does not reconcile to the Stock Value exposure used by this report.

This report shows how old stock is and which aged stock is not selling. It does not say why stock is ageing, or what to do about it.
